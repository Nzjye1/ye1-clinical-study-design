# Ye1 临床研究方案与数据准备

**从临床工作和已有资料中寻找研究方向，形成研究方案并准备数据。**

面向支持 Skill 指引的各类 AI Agent，用自然语言交办任务。

## 能做什么

- 从医生的临床工作、已有资料或研究目标出发，寻找可开展的研究问题。
- 围绕候选方向检索文献，比较已有研究、临床价值和数据条件。
- 在本地准备和清洗已有科研数据，保留原始文件与研究时间信息。
- 根据明确的分组和结局，衔接现有分析能力开展首轮统计和结果判断。
- 制定研究方案、收数思路和所需字段，按需要生成收集表。
- 结合研究进度衔接伦理申请、研究登记及后续分析工作。

## 安装到你的 Agent

将下面这段话发给你的 Agent：

> 请从 https://github.com/Nzjye1/ye1-clinical-study-design 获取 Ye1 临床研究方案与数据准备。读取 `skills/ye1-clinical-study-design/SKILL.md`，按照当前 Agent 支持的方式安装完整 Skill 文件夹并检查所需工具，然后告诉我如何开始使用。

也可以下载 [通用 Skill 包](downloads/ye1-clinical-study-design-skill.zip)，解压后将完整文件夹导入或放入所用 Agent 的技能目录；WorkBuddy 用户可使用 [WorkBuddy 导入包](downloads/ye1-clinical-study-design-workbuddy.zip)。

根据任务使用当前 Agent 可用的检索、文件和文档工具。

## 开始使用

你可以从当前最需要的环节开始，把下面适合你的一段话发给 Agent。

### 1. 没有数据，从科室情况寻找方向

> 我在某临床科室工作，目前还没有整理好的数据，请结合我们常见患者、检查和治疗，查阅文献并推荐可开展的研究方向。

### 2. 已经有临床资料

> 我有一份本地临床数据，请先生成工作副本并整理数据，再结合研究问题做初步分析，查阅相关文献，看看适合开展什么研究。

### 3. 先做首轮统计

> 我的分组和结局已经明确，请基于这份研究数据做基础描述和组间比较，整理各组人数、结果和适用的统计检验，再给我一个初步判断。

### 4. 评估一个已有想法

> 我想研究这个临床问题，请帮我检索相近文献，比较已有研究和我的数据条件，判断有哪些可行的切入点。

### 5. 制定研究方案

> 我已经选定研究方向，请帮我明确研究对象、分组、结局、观察时间和分析思路，整理一份可继续完善的研究方案。

### 6. 设计收数表

> 请根据这项研究方案，列出需要收集的患者资料、检查、治疗和结局字段，并制作方便填写的收数表。

### 7. 继续已有项目

> 我之前已经形成了研究方案和一部分数据，请沿用现有资料，帮我检查还需要补充哪些关键字段，以及接下来如何推进。

### 8. 衔接伦理和后续分析

> 研究方案已经形成，请根据现有方案和收数信息继续准备伦理申请材料，并整理后续统计分析需要的资料。
