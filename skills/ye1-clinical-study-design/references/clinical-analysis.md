# 本机临床分析衔接

患者数据到手且需要分析时，先查找 `ye1-clinical-analysis`：检查宿主实际提供的可调用 Skill、当前研究项目的 `.agents/skills/ye1-clinical-analysis/SKILL.md` 及数据所在项目。不依赖联网，也不写死某台电脑的绝对路径。能确认模块存在但未启用或不可运行时，说明实际状态；无法核实安装状态时，只说“目前没有找到可用模块”，不要断言未安装。

## 找到模块

读取实际找到的模块版本的 `SKILL.md`、方法和本地输入说明，按它当前支持的接口、条件和确认方式执行；不要套用旧版本的终端确认或预设命令。如果模块使用 `scripts/toolkit.py`，可由 Agent 查询可用方法及其要求。选择与分组、结局、观察单位和数据条件相符的基础描述、比较及 P 值，无需医生编写配置文件或先完成完整研究方案。模块或依赖不能运行时说明原因，不假称分析完成；可询问医生是否需要协助检查启用状态或了解安装条件。

在本地准备模块所需数据和任务，保留清洗工作文件及所有时间，未用于本次比较的研究列不从原工作文件删除。患者逐行记录、身份对应表、私有任务和日志留在本机，不发到模型或对话。按实际模块及客户授权处理允许展示的汇总与图表；不代替客户确认，也不绕过模块实际要求。

## 没找到模块

需要统计且当前没有找到可用模块时，简短说明该模块的用途，明确问医生是否需要帮忙评估安装；同时保留原先的基础分析和暂不分析选项。回复中直接提到“安装”，让医生知道这一选择。不要自动下载、安装、更新，也不要把其他程序称为医生的分析模块。例如：

> 我目前没有找到可用的临床分析模块。它可以帮助完成统计分析，需要我帮您看看是否适合安装吗？也可以先为这次数据写一版基础分析，或者暂时不做分析。

医生只想了解时，结合实际任务和宿主环境解释作用、可用来源及需要的条件；未知的来源、兼容性和依赖说明待核实，不假称可以一键安装或已在某个市场上架。医生明确要求安装后，按宿主实际支持的方式及医生提供或确认的来源协助；如本机已有安装包，可使用该包，若技能市场确有该模块，可按实际界面引导。需要额外系统软件或超出已授权范围的操作时，先说明并取得相应同意。没有可用来源、宿主不支持或安装失败时如实告知，并继续提供现写基础分析或不分析的选择；不绕过限制，不声称安装成功。

医生已明确要求编写基础分析时直接执行，不重复询问。医生选择写一版后，Agent 可使用本机已有工具为当前数据编写并运行所需的基础比较；说明这是本次编写的基础分析，不冒称已安装 Ye1 模块。选择适合数据的方法，核对人数、分母和结果；没有条件计算时如实说明，不编造 P 值。患者逐行数据仍留在本机。

医生选择不分析时，不运行统计检验；保留已完成的工作文件，并按医生需要继续不依赖统计的事项。客户需要提供已有模块位置或安装包时，可按其提供的信息重新查找。任何下载、安装或更新都要先取得医生明确同意；已经明确要求的操作不重复询问。

## 反馈结果

实际计算完成后，用简短表格或实际生成并检查过的图呈现组别、人数、结局值或比例、P 值及最主要的数据问题；结合结果给出是否值得继续评估的初步判断。图表如由 Agent 根据核对后的汇总另行绘制，要与分析模块的原图区分。图件失败、依赖缺失或其他警告须如实说明，不能仅凭文件存在或退出码就称全部成功。后续正式推荐具体方向前仍须查文献。
